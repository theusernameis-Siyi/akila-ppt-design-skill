# Akila PPT Design Skill for Claude Code

This repository packages the Akila PPT design skill for Claude Code.

## Use in Claude Code

1. Clone this repository.
2. Open Claude Code from the repository root:

```bash
cd akila-ppt-design-skill
claude
```

Claude Code discovers project skills from `.claude/skills/<skill-name>/SKILL.md`.

Use it naturally:

```text
Help me create an Akila investor deck.
```

Or invoke it directly:

```text
/akila-ppt-design-skill
```

## Important

Keep this repository private. The skill bundles an Akila PPT template asset under `.claude/skills/akila-ppt-design-skill/assets/`.
