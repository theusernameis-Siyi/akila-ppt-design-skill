# Akila Slide Layout Index

Use this index to choose layouts from `assets/akila-slide-master-template.pptx`.

The Akila PPT template contains no example-ranking categories. All slides are approved references. Do not add any ranking split unless Siyi explicitly marks it.

## Reuse Modes

| Mode | Meaning |
| --- | --- |
| Reusable | Use directly when the new content matches the same slide purpose and density. |
| Adaptable | Use as a starting structure, then adjust module count, hierarchy, spacing, color emphasis, or image use based on the actual content. |
| Reference only | Use for visual reference only. Rebuild the structure according to the new content purpose, data relationship, and message hierarchy. |
| Usage guide | Instruction material for designers and AI. Do not use as an output slide layout. |
